# SteamGameBridge v0.2.0

- 内置终末地、绝区零、鸣潮、崩坏3预设，支持自定义 Steam AppID 和多游戏管理。
- 支持直接启动、官方启动器、第三方包装器和 Starward 启动。
- 绝区零和崩坏3支持 Starward 时长联动。
- 支持自动检索本地游戏、Windows 深色模式。
- 已有 Steam 安装可检查、重新接入或确认删除，处理中断后可恢复。
- 首次运行选择数据保存位置，支持转移数据目录；预览不创建启动组件。

下载后解压，运行 `SteamGameBridge.exe`。

- `small`：需要 .NET 10 Desktop Runtime x64。
- `self-contained`：内置运行时，无需另装 .NET。

文件校验值见 `SHA256SUMS.txt`。
