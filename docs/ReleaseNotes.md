# v0.1.0-preview.1

首个独立实验预览版，面向 Windows x64。使用正式 AppID 4162040 的安装清单及启动选项，调用已有《绝区零》官方国服客户端；不需要先下载 Steam 国际服游戏资源。

提供一键接入、元数据获取／导入、明确账号选择、原启动项备份、检查修复、一键恢复及托盘维护。程序不修改国服受保护文件，不注入、不绕过反作弊，也不修改 Starward。

下载 `small` 包需要 .NET 10 Desktop Runtime；`self-contained` 包内置运行时。校验值见 `SHA256SUMS.txt`。

本地 97 项隔离测试通过；本次 GitHub 构建结果请查看对应 Actions 记录。**真实国服登录、Steam 游玩时长、好友状态、Overlay、截图及更新后持续可用性尚未验收。** 工具本身不下载国际服资源，但不能保证 Steam 的校验或更新永远零下载。

解压后运行 `ZZZSteamBridge.exe`，按 README 选择账号及国服路径；接入／恢复前完全退出 Steam。要求管理员权限的国服须通过正常 UAC 打开管理员 Steam。程序未作商业代码签名。
